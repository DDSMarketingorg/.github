# DDSMarketingorg/.github

Default community health files for every repository in this organisation.

GitHub applies a file here to any repository in the org that has no file of the same type,
private repositories included. This repository has to stay public for that to work.

| File | Applies as |
|---|---|
| `pull_request_template.md` | The PR description every repository starts from. |

A repository that adds its own `pull_request_template.md` replaces this one completely. The two
are never merged. Change it here rather than copying it.
